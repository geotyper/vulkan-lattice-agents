# Переход на дискретную решётку

Форк `vulkan-neuroevolution-agents` от `main` (ba9abbf). Полная история 2D-проекта
сохранена: всё удалённое ниже остаётся доступным через `git log`/`git show`.

## Открытый вопрос — решить до первой строчки кода

100x100x50 = 500 000 клеток = 2 МБ occupancy на **один** мир. Сейчас логических
миров ~170 (2048 агентов по 12 на мир). 340 МБ только под занятость, 3D-trail
(500k x RGB) — под гигабайт. Не сходится. Плюс 12 агентов на 500k клеток — это
плотность 0.002%, они никогда не встретятся, а вся работа последних веток
(chain, formations, чтение скорости соседей) — про соседство.

- **A. Решётка маленькая, миров много.** 32x32x16 = 16k клеток, 64 КБ на мир.
  Топология GA (512 геномов x 4 трайла x группы), свипы и статистика выживают
  без изменений. 100x100x50 — только один показательный мир во вьюпорте.
- **B. Решётка большая, миров единицы.** 8 миров по тысячам агентов. Один геном
  управляет сотнями тел — однородный рой, морфогенез/самосборка. Оценка
  приспособленности шумнее (мало трайлов), поведение — то, ради чего берут
  решётку такого размера.

Рекомендация: начать с A, размер решётки вывести ползунком.

## Что становится проще

Пространственный хеш с `atomicExchange` не нужен: в плотной решётке индекс это
сама решётка, `cell = z*W*H + y*W + x`, один int на клетку. Соседи —
константное смещение, без связных списков. Столкновения — заявка на клетку
через `atomicCompSwap(occupancy[cell], -1, agentId)`, а не импульс.

## Порядок работ

1. Удалить перечисленное выше, из `vkneuro_domain` оставить `neuro/` +
   `evolution/` + `WorldSnapshot` + `ExperimentSweep`; переименовать таргет
   так, чтобы в имени не было "world".
2. `LatticeKernel.inl` по образцу `BrainKernel.inl`: индексация клеток,
   6/26-соседство, правило движения. Сразу с CPU/GPU-паритетом и тестом на
   паритет — как уже сделано для мозга.
3. Новый `AgentState`.
4. Сенсоры как чтение окрестности; ширина входного вектора идёт в `BrainShape`.
5. Рендер 3D — последним. До него хватает headless и статистики.

GA всё равно переписывается под однородный рой — это ровно тот момент, когда
ES-апдейт вместо турнирной селекции встаёт естественно, до правок модели нейрона.
Каждый новый параметр — ползунком в UI, не только флагом headless.
